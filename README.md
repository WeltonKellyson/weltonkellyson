## 👋 Sobre mim

Sou **Desenvolvedor Full Stack** e construo sistemas de verdade: do banco de dados à interface, em produção e com usuários reais.

Em 2 anos saí do suporte técnico para construir, junto com o time de TI da **Health & Safety**, uma suíte com **mais de 10 sistemas corporativos** criados do zero, usados todo dia pelos times de vendas, RH, suporte e operações.

Meu trabalho conecta quatro áreas:

- **Front-end:** React, TypeScript, JavaScript e Tailwind CSS.
- **Back-end:** Python, FastAPI, Node.js e APIs REST.
- **Dados:** PostgreSQL, SQL Server, integrações com ERP e dashboards.
- **IA & Automação:** OpenAI API e n8n integrados a sistemas em produção.

## 🚀 Projetos em destaque

> Sistemas internos da Health & Safety, desenvolvidos em parceria com o time de TI. O código é privado, mas as telas (com dados fictícios) estão no repositório **[showcase](https://github.com/WeltonKellyson/showcase)** 👀

### 🎫 HelpHS
**Plataforma de Help Desk para clientes externos**

Substituiu o atendimento que antes era feito via WhatsApp, sem controle, SLA ou histórico.

- kanban de tickets com status em tempo real
- SLA automático com alertas de vencimento
- dashboard com CSAT, tempo médio de resolução e conformidade de SLA
- base de conhecimento, perfis de acesso e audit log

**Stack:** React · TypeScript · Tailwind · Python · FastAPI · PostgreSQL · Docker

### 🧠 TalentHS
**Plataforma de RH com psicometria e IA**

O projeto mais complexo que já desenvolvi em termos de produto e UX.

- psicometria DISC + OCEAN por colaborador
- mapa 9Box para avaliação de desempenho
- chat com IA personalizado por perfil
- dashboards de desenvolvimento individual e de equipe

**Stack:** React · TypeScript · Tailwind · Python · FastAPI · PostgreSQL · OpenAI API · Docker

### 🏷️ ControlHS
**Gestão de patrimônio**

- mais de 400 itens e R$ 200 mil em ativos gerenciados
- transferências entre setores com rastreabilidade
- baixas, cálculo automático de depreciação e dashboard de KPIs
- log de auditoria e controle de acesso por perfis

**Stack:** React · TypeScript · Python · FastAPI · PostgreSQL · Docker · Easypanel

### 📈 GrowthHS
**CRM próprio que substituiu o Pipedrive**

- pipeline com boards e cards sob medida para o fluxo comercial
- integração com RD Station para ingestão de leads
- histórico de interações e visão completa do funil

**Stack:** React · TypeScript · Tailwind · Python · FastAPI · PostgreSQL

### ⚡ Outros sistemas
- **DataCoreHS:** dashboards integrados ao ERP, com +40% de eficiência na análise
- **HealthScore:** treinamento de vendas com IA, com −30% no tempo de treinamento
- **AI Recruiter:** triagem de currículos com n8n + OpenAI, com −70% no tempo do processo seletivo
- **ChamadosHS:** help desk interno entre colaboradores e TI
- **AppHealth:** app mobile em Flutter com integração Bluetooth aos equipamentos
